# AutoLog

AutoLog is a personal car service and maintenance log app for tracking vehicle repairs, oil changes, tire replacements, and technical inspections. It helps car owners organize service history from oldest to newest, attach receipt photos, and monitor total maintenance expenses

## Run the project

```bash
npm install
npx expo start
```

## Features

- [x] List of car services (mock data)
- [x] Service card and service details components
- [ ] Consistent theme and responsive styling
- [ ] FlatList with empty and loading states
- [ ] Service details screen (dynamic route navigation)
- [ ] Bottom tabs (Services Log, Car Info, Expense Summary) and modal screen
- [ ] Add and edit service forms with validation
- [ ] Global state for selected car and service records
- [ ] Local persistence on device
- [ ] Camera / image picker for service receipts
- [ ] Supabase authentication (login/register) and cloud storage
